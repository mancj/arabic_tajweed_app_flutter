## 5. Сессия

- **До 20 заданий**, виден единый прогресс-бар с фактической длиной занятия. Обычно блоки закрепления, новое и повторение заполняют весь бюджет. Занятие может закончиться раньше, если в текущем разделе не хватает знакомого материала; единственное автоматическое повторение завершённого раздела — до двух сборок форм букв в огласовках.
- Ошибка → показать верный ответ + короткое объяснение → вернуть задание через несколько шагов. Если такая же проверка этой буквы уже есть впереди, отдельная копия не добавляется; поэтому в узком двухбуквенном уроке одинаковый тест встречается не больше двух раз на букву. В полной сессии повтор заменяет добавочное задание, но не вытесняет обязательную форму или режим и не превышает бюджет.
- В обводке промах — штрих, который не продвинул текущую часть буквы: он стирается с холста сразу, а штрих, продвинувший часть из нескольких линий, остаётся. После **трёх промахов подряд по одной части** холст сам показывает, как пишется: открывает контур и показ, и по памяти, и по контуру. Кнопка «Не помню» в письме по памяти открывает тот же контур. Оба способа — подсказка, а не ответ или ошибка: окно результата не появляется и событие прогресса не записывается. Человек обводит по подсказке, и только собранная буква засчитывается верным ответом. Допуск проверки при этом не смягчается: подсказка честнее сниженной планки, а человек, у которого не выходит линия, не застревает на букве без помощи. `?` Число 3 подлежит калибровке.
- Ответ со второй попытки не даёт продвижения по состоянию атома, но и не считается повторной ошибкой.

Жизней / сердечек нет.

Выход без произношения не пишет ответ и временно убирает голос из всех
уроков до следующего запуска приложения. Оставшиеся голосовые задания
заменяются практикой знакомого материала текущего раздела. Исходное число
мест сохраняется, если материала хватает в пределах повторов; новый блок
ради замены не вводится. Постоянный системный запрет микрофона проверяется
при каждом запуске отдельно (см. §4).

## 6. Уроки: граф вместо расписания

Фиксированной программы «урок 7 вводит `ج` и `ح`» **нет**. Такое расписание убивает адаптивность: буква вводилась бы независимо от того, готов человек или нет.

Хранятся **ограничения и заготовки**, а не последовательность. Порядок уроков выводит алгоритм.

Учебный контент — граф знаний, темы, шаблоны уроков, тексты объяснений, данные по буквам — лежит **JSON-файлами в ассетах приложения**. Версионируется через git, работает офлайн, правка требует релиза. Формат сразу проектируется так, чтобы те же файлы можно было подтягивать с сервера, когда контент начнёт меняться чаще релизов.

### 6.1 Граф знаний

Узлы — атомы и понятия, рёбра — «что после чего *можно* вводить».

```
понятие «формы»    requires: —
понятие «точки»    requires: [ا, понятие «формы»]
ب                  requires: [понятие «точки»]
ث                  requires: [ب, ت]
понятие «огласовки»  requires: [завершены 28 букв и все их формы]
понятие «соединение» requires: [огласовки на 28 отдельных буквах в known]
```

Это не порядок уроков, а рёбра. Условия бывают двух видов: конкретные
зависимости (`ث` после `ب` и `ت`) и пороговые (`28 букв в known`). Порядок
тем дополнительно не позволяет связкам нескольких букв обогнать огласовки.

Пороговые условия считаются по **`known`, а не `mastered`**. `mastered` требует отложенных подтверждений: для букв — через 1/2/4 сессии, для остального материала — по календарю из §3. Привязка тем к нему задерживала бы курс даже тогда, когда человек всё уже узнаёт. `known` — это «узнаёт уверенно», и этого для открытия следующего понятия достаточно. После перехода к новому разделу незавершённые подтверждения старого не удерживают пользователя в нём.

### 6.2 Шаблоны уроков

Не «урок 7», а «учебный блок такого типа». Шаблон задаёт структуру блока и правила подбора, но **не конкретные буквы**. Одна сессия может начать с короткого добора пробелов и перейти к одному цельному новому блоку; два разных новых блока с заданиями в одну сессию не объединяются. Тема только с объяснением может стать вступлением к первому блоку с заданиями того же раздела.

| Шаблон | Когда применяется | Состав |
|---|---|---|
| `введение понятия` | открылось новое понятие | длинный intro + закрепление понятия + повтор |
| `введение буквы` | нагрузка в норме, в графе есть доступный блок | intro + цельная группа новых букв + закрепление + повтор |
| `повторение` | нагрузка выше порога | только повтор, новых атомов нет |
| `смешанное повторение` | после нового урока ещё не пройдены два зачётных повтора в этот день | материал из разных пройденных наборов, без нового |
| `рубеж алфавита` | закончены 7, 15, 21 или 28 букв | обязательная смешанная проверка без нового |
| `соединение` | понятие «соединение» открыто | слоги из освоенных букв |

Блок **повтора берётся из общей очереди тем текущего раздела**, а не из атомов самой темы: так предыдущие темы раздела возвращаются. Исключение для огласовок — две сборки форм из алфавита. При явном выборе старого раздела его темы снова доступны для практики. Из двадцати мест не меньше четырёх резервируются возврату, если в текущем разделе есть знакомый материал; в огласовках две сборки старых форм входят в эту долю; остальные — теме урока. Сначала берётся всё, что созрело по интервальной очереди; если этого мало, резерв добирается любым знакомым материалом прежних тем того же раздела. После первого набора букв повтор не может исчезнуть только потому, что его срок ещё не наступил. Один атом занимает не больше пяти заданий, иначе урок вырождается в одну букву. Созревшие формы одной четырёхформенной буквы считаются одним семейным повтором и занимают один слот сборки.

Для полного блока ровно из двух отдельных букв действует более строгий предел: по четыре задания на букву — обводка, узнавание, письмо по памяти и произношение. Если голос технически недоступен, его место может занять второе узнавание, но третьего одинакового теста не будет. Все свободные места получают буквы прошлых тем текущего раздела: сначала созревшие по интервалу, затем остальные знакомые. Если не хватает и этого, занятие заканчивается раньше. Следующий новый авторский блок ради числа 20 в ту же сессию не вводится; это правило действует для любого урока с новым материалом.

Очередь — интервальная. Атом, не дошедший до `known`, просится в повтор
каждый урок. Буквы и их формы после `known` возвращаются через 1, затем 2
и 4 сессии; каждый своевременный чистый повтор в новой сессии даёт одно
подтверждение, третье переводит форму в `mastered`. Несколько ответов в
одной сессии не увеличивают интервал. Ошибка откатывает форму в `learning`
и обнуляет подтверждения. Для остальных типов материала очередь сохраняет
общую схему 2, 4, 8, 16 сессий, а переход в `mastered` дополнительно требует
календарных интервалов из §3. Внутри очереди сначала недоученные, затем те,
у кого срок повторения вышел раньше.

Общий скелет сессии; части `пробел` и `новое` могут повторяться:
```
[ пробел ]     обязательный короткий добор недоученного
[ intro ]      объяснение нового цельного материала
[ новое + повтор ]  закрепление и очередь старого материала
[итог]         что выучено, что открылось
```

В уроке с новым материалом сначала каждая новая буква получает хотя бы одно задание. Затем возврат из общей очереди подмешивается в закрепление в случайных местах. Пока обе очереди не пусты, старый материал не идёт дважды подряд, а материал темы — больше двух раз подряд. Так старые буквы не собираются предсказуемым хвостом, а пара новых букв не превращается в механическое чередование. Порядок упражнений одной буквы сохраняется: обводка по контуру не может оказаться после письма по памяти. Если нового материала нет, повтор остаётся одним блоком.

В огласовках занятие получает две сборки форм разных знакомых букв из первого
раздела. Первое место получает давно не встречавшаяся буква, второе — буква
с ошибками или слабым знанием; при отсутствии таких — ещё одна давно не
повторявшаяся. Пул включает весь алфавит: четыре формы у 22 букв и две
(отдельно / в конце) у `ا د ذ ر ز و`. Предел общий для всех блоков одной
сессии, включая пропуски. Сборки занимают свободные места или заменяют
добавочные задания; обязательное письмо, запланированный голос
и звуковые сборки сохраняются. Если весь остаток занят обязательной практикой,
сборок меньше. Исправление ошибки остаётся в том же задании, без новой копии
сверх двух мест. Результаты записываются каждой форме обычным путём, но
не возвращают человека в алфавит и не закрывают уже открытые темы. Проход
всех 28 букв не обязателен; в связках и словах эта добавка прекращается.

В занятии с огласованными слогами до трёх одиночных тестов на разных буквах
превращаются в звуковые сборки. Каждая проверяет три слога и занимает прежнее
одно место из двадцати. Доступны после знакомства со
знаками на ба, когда все три слога буквы уже введены или входят в текущую
авторскую часть; на букву не более одной сборки за занятие. Выборочный набор
не расширяется ради сборки: недостающие сочетания не вводятся случайно. У новых слогов сохраняется
обязательное письмо; у освоенных можно заменить одиночный
тест любого направления. Короткий добор получает соразмерное число сборок,
а общий предел в три учитывает уже выполненные сборки этой сессии.
После введения трёх знаков при наличии слогов трёх знакомых букв до двух
сборок используют разные буквы: звуковые слоты показывают букву без знака,
а три огласовки в вариантах можно выбирать повторно. Как минимум один знак
повторяется. В полном занятии остаются две сборки на разных буквах и одна
на одной; короткий добор получает соразмерную долю обоих форматов. При
пересчёте плана учитывается число уже предложенных сборок каждого формата,
включая пропущенные; повторные попытки одного задания не увеличивают его.
Повтор ошибки подчиняется общим правилам. Результаты учитываются по трём
слогам, одиночная практика чтения и обязательное дорисовывание сохраняются.
Если из-за места для повторения не все слоги получили дорисовывание в первом
занятии, незакрытая тема добирает именно их в следующем блоке практики.

После знакомства с тремя знаками одиночное чтение слогов использует три
равноправных формата: выбрать написание по звуку, выбрать звук по написанию
и собрать звучащий слог из буквы и знака. Они делят оставшиеся места примерно
поровну, с учётом уже предложенных форматов при доборе внутри одной сессии.
Сборка не увеличивает длину занятия и не расходует предел трёх звуковых сборок:
она проверяет один слог, а не семейство. Не требуется дать все три формата
каждому слогу в одном уроке: они встречаются наравне во всём занятии.
Варианты содержат только знакомые буквы и знаки.

С третьей темы огласовок (`m.haraka.group1`, «ت ك د ر») до двух добавочных
одиночных тестов заменяются вводными сборками: одна «Дострой соединение»
и одна «Собери слово по шагам». В полном занятии это 2 из 20 мест, в занятии
из 10–19 — максимум одно; форматы чередуются между сессиями. Более короткий
блок не получает добавку. При доборе учитываются общее число мест и уже
предложенные форматы, включая пропуски; исправление ошибки не добавляет копию.
Письмо, запланированный голос, семейные звуковые сборки и два повтора форм
сохраняются. Если свободных добавочных тестов меньше, вводных сборок меньше.
Используются знакомые формы и только введённые слоги либо слоги текущей части
после их объяснений. Будущие темы через них не открываются. В первых двух
темах и соседних разделах эта добавка не действует. Частичные результаты
записываются формам и слогам по §4, не заменяя обязательную практику.

Чтение слогов вслух в блоке огласовок занимает не более 15% запланированных мест:
до трёх заданий из двадцати. В коротком блоке предел считается от его
фактической длины с округлением вниз, но допускается одно голосовое задание.
Блоки одной сессии используют общий накопленный бюджет и учитывают уже
предложенный голос. Сначала выбирается новый материал, затем пропущенная
обязательная голосовая практика, затем материал полного повтора темы;
остальные знакомые элементы выбираются случайно. На один атом — не более
одного запланированного голоса за занятие; учебный повтор ошибки сохраняется.
Выбранный новый элемент читается сразу после объяснения, уже знакомый —
после письма или в подходящем активном слоте. Единственная встреча знакомого
слога не обязана быть голосовой. Места письма сохраняются, общий бюджет не растёт.
Пока голос доступен, он нужен для завершения темы наряду с письмом; техническое
отключение снимает этот критерий так же, как в алфавите.
К произношению отдельных букв этот предел не применяется: оно сохраняет
прежнюю частоту — один раз на каждую базовую букву темы или общего повтора.

Каждый урок форм включает все заявленные формы букв темы в одном сеансе,
блоками по позиции (см. §2). Хотя бы одно задание выделяется каждой форме;
оставшиеся места идут на закрепление. Если у букв есть только конечные формы
(`د ذ ر ز`), достаточно одного блока. Ошибки возвращаются на повтор по §5.
У четырёхформенной буквы одна из встреч — сборка всего семейства, поэтому
каждая соединённая форма получает две разные проверки за один идеальный урок.
Этого достаточно для первого `known`; изолированная буква по-прежнему требует
три чистых ответа, два типа заданий, письмо и произношение. Благодаря этому
идеально пройденный урок форм не создаёт отдельный день добора только из-за
неравномерного распределения двадцати мест.

Это правило действует при знакомстве с новым блоком и явном выборе
полного повтора темы в оглавлении. Автоматическое закрепление уже
показанного материала работает только с пробелами (см. §6.3).
Перед заданиями каждая форма темы получает объяснение. Лимит заданий,
накопленный прогресс и зависимости не могут исключать материал из темы.
Перед первой такой карточкой для каждой буквы показывается сводный обзор всех
её форм. Он не считается заданием, отдельным атомом или знакомством с ещё не
разобранными формами: их подробные карточки остаются в своих блоках.
До объяснений проверяется, что весь материал доступен и помещается вместе
с обязательным повторением старого. Если нет, нужно изменить порядок,
зависимости или разделить тему в программе курса; неполный урок не создаётся.

В `intro` для букв `ا د ذ ر ز و` обязательно показывается правило о несоединении влево.

Кнопка «Конспект занятия» видна в шапке с начала урока и открывает отдельный
экран. В нём доступны закрытые в этом занятии объяснения и обзоры форм, а
также объяснения материала, который попал в задания на повторение текущей
сессии. Варианты неверных ответов в конспект не добавляются. Новая тема
попадает туда только после показа; если материала пока нет, экран показывает
короткую подсказку. Карточки листаются свайпом вправо и влево; верхние
вкладки позволяют сразу выбрать нужную. Длинная карточка прокручивается
вверх и вниз. Можно перечитать её и прослушать пример. Возврат
сохраняет выбранный ответ и рисунок, а просмотр не создаёт событий прогресса.
После «Понятно» кнопка коротко анимирует счётчик новых карточек. Счётчик
растёт только при первом добавлении объяснения, сбрасывается при открытии
конспекта и не включает заранее доступные конспекты повторения.
Конспект живёт только до конца занятия.

### 6.3 Планировщик (на клиенте)

Перед началом и после каждого завершённого блока планировщик заново считает прогресс и выбирает следующую посильную цель:

1. Если одновременно отложено больше четырёх элементов — закрепление
   с досрочным возвратом самого старого отложенного.
2. Если сегодня уже завершён урок с новым материалом и после него
   ещё нет двух зачётных уроков без нового — выдаём полное смешанное
   повторение внутри текущего раздела. Оно включает и пробелы текущей темы, но не зацикливается только
   на них. Если на этой позиции уже подошёл обязательный рубеж алфавита, он служит
   таким повторением.
3. Если есть начатый доступный блок с неосвоенным материалом — продолжаем
   его: ещё не показанное объясняем, уже показанное закрепляем коротко.
   Если весь блок уже показан, выбираем только неосвоенные элементы,
   начиная с тех, которые дольше не встречались. При нескольких
   таких блоках выбираем первый по программе в выбранном разделе.
   Этот приоритет сильнее нового понятия и гарантии темпа.
4. Если достигнут очередной рубеж алфавита, перед вводом следующей группы букв или выходом из алфавита нужна успешная обязательная смешанная проверка. До неё можно закончить формы уже введённой группы.
5. Если нагрузка выше порога — закрепление. После двух занятий без нового материала можно ввести доступный блок, но эта гарантия не обходит дневной цикл повторений и рубежи алфавита.
6. Иначе — первый незавершённый блок нового материала по порядку в
   оглавлении выбранного раздела. Техническая готовность более поздней темы
   не позволяет ей обогнать программу курса. Следующий этап начинается
   только после освоения или успешной входной проверки всех тем предыдущего:
   основной раздел соединений начинается после завершения огласовок на
   отдельных буквах. Исключение — небольшие вводные сборки с третьей темы
   огласовок, без нового материала.
7. Если нового доступного блока нет — повторение из общей очереди. Когда срок
   повторения ещё не подошёл, ручной запуск занятия всё равно даёт практику
   знакомого материала, а не пустой экран.

Дневной темп относится ко **всему новому материалу курса**: буквам и их формам, огласовкам, соединениям, словам, понятиям и следующим этапам. После завершённого урока с новым материалом следующий новый авторский блок в тот же местный календарный день закрыт. Повторение можно запускать без ограничений. Первый блок нового раздела открывается сразу, если в нём ещё нет материала для повторения; повторять завершённый раздел ради доступа к новому не нужно. После первого занятия с заданиями дневной цикл снова действует. На следующем календарном дне один следующий новый блок снова доступен сразу, если выполнены зависимости и обязательный рубеж алфавита.

Следующий новый блок в тот же день открывают **два успешно завершённых урока без нового материала после последнего нового урока**. Более поздний урок с новым начинает отсчёт заново. Успешный повтор — не менее 8 заданий и не менее 80% верных ответов с первой попытки; пропуск считается неудачной встречей, а скорость ответа на этот допуск не влияет. Короткий незавершённый добор и брошенное занятие не засчитываются. Название плана не важно: полный обычный повтор тоже считается, если в его сессии действительно не было `AtomIntroduced`. Обязательный рубеж является уроком без нового и может дать один из двух зачётов.

Рубежи стоят после 7, 15, 21 и 28 изолированных букв: это цельные отрезки по 7, 8, 6 и 7 букв, совпадающие с границами авторских групп. Каждая буква нового отрезка встречается в рубеже хотя бы раз. Незачётный рубеж повторяется и не открывает следующую группу; заработанные дневные окна его не обходят.
Если прогресс был накоплен до появления этой механики и достигнуто сразу несколько границ, назначается только самый поздний достигнутый рубеж; его зачёт покрывает все более ранние. Так старый пользователь не получает четыре исторические проверки подряд.

В любом смешанном занятии последний введённый набор занимает не более 40% заданий, если раннего материала текущего раздела достаточно. Остальные места получают более старые, слабые и созревшие элементы этого же раздела. После перехода к огласовкам отдельные буквы без огласовок не получают обычных самостоятельных заданий, кроме двух сборок форм за занятие; после перехода к связкам так же уходят задания раздела огласовок. Ответы в новом разделе не обязаны доводить атомы старого до `mastered`.

Выход из занятия, просмотр объяснения и отметка о завершении не означают
готовность к следующему материалу. Готовность блока: понятия объяснены,
все проверяемые элементы достигли `known`; для базовых букв также выполнены
оба режима письма, если доступен контур, и произношение, пока оно включено.
Успешные режимы
считаются по всей истории верных ответов, включая медленные и исправленные;
достаточная уверенность проверяется отдельно состоянием `known`.
Зачёт `known + weak` по входной проверке или облегчённому критерию остаётся
исключением: обязательные учебные режимы не требуют повторного прохождения.

Сессия имеет верхний бюджет `tasksPerSession` (20 сейчас; число может быть откалибровано позже). Короткое закрепление — первый блок этой сессии, а не отдельное занятие. Если после него открылся один новый цельный блок и все его обязательные задания помещаются в остаток, он вводится сразу. После блока с новым материалом и заданиями остаток получает только повторение; второй такой блок не добавляется. Тема «Что такое огласовки» содержит только объяснение и продолжается в том же занятии упражнениями с тремя знаками. Восемь групп букв сохраняются как темы; большие группы задают в `lessonBlocks` части максимум по пять новых слогов. Планировщик и короткий добор работают с первой незавершённой частью. Следующая вводится после её освоения, включая обязательные режимы; новый материал каждой части подчиняется общему дневному темпу. Смешанное повторение и рубеж всегда заканчивают свою сессию без динамического добавления нового. У полного блока из двух отдельных букв свободные места получают сначала созревший, затем любой знакомый материал текущего раздела. При нехватке материала этого раздела сессия завершается с фактически меньшим числом заданий.

Внутри короткого добора уже освоенные элементы не мешаются с пробелами. Если элемент уже в `known`, но пропущен обязательный режим, даётся только этот режим. Исключение — чтение слога вслух в огласовках с пределом 15%: не выбранные в этом блоке элементы получают доступную практику чтения или письма, а голосовой пробел остаётся для следующего занятия. Иначе нужно 2–3 встречи с учётом серии верных ответов и недостающих режимов. Ошибка возвращает задание, но не раздувает общий бюджет: повтор вытесняет добавочное, но не обязательное задание.

Если ошибка сбросила чистую серию буквы, добор восстанавливает не только
число ответов, но и нужное разнообразие режимов: один и тот же тест не может
быть единственным способом снова дойти до `known`. Предел в пять заданий на
атом считается по всему занятию, включая заново построенные блоки после
добора; исчерпанный пробел не заполняет собой остаток из двадцати заданий.

Фиксированная очередь незавершённого занятия не сохраняется. При каждом
возвращении материал и упражнения собираются по журналу ответов. Новый материал
открывает не само число заходов, а только два успешных итога полностью
завершённых сессий без первого знакомства с атомом после последнего нового урока. Незаконченный
урок с новым не запускает этот отсчёт: при возвращении человек продолжает его.
После серии
ошибок временно отложенный элемент не возвращается досрочно, кроме случая
из пункта 1: содержащий его блок ждёт окончания паузы, доступное повторение
продолжается по остальным элементам.

Мелкие авторские блоки в JSON задают цельный объём материала: группу базовых
букв или все соединённые формы этой группы. Темы служат оглавлением;
фиксированного числа занятий нет. Планировщик добавляет столько закреплений,
сколько требуется по знаниям, и после освоения добавляет новое.
Каждый следующий блок букв/форм требует освоенности предыдущего материала.
В новом блоке сохраняются все обязательные объяснения и упражнения из §6.2.
Проверка вместимости происходит до запуска; слишком большой блок нужно
разделить в контенте, а не исключать отдельные формы.

Соединение нескольких букв открывается после трёх знаков на ба и 45
выбранных обязательных слогов на остальных 27 отдельных буквах. Текущие сочетания требуют конкретных форм входящих букв и вынесены
в отдельные небольшие блоки. Пока они сохранены без огласовок; следующая
правка контента добавит огласовки, не меняя их место в программе. В
сочетаниях доступны задания в обе стороны: выбрать запись по названиям букв
и определить буквы по записи.
Хамза и другие знаки также получают вопросы в обе стороны, чтобы достижение
`known` не было невозможно из-за единственного режима.

Для графов без авторских блоков сохраняется подбор отдельных доступных
элементов. Числа нагрузки и гарантии темпа остаются настраиваемыми в коде.

### 6.4 Защита от застревания

Ограничение нагрузки («нагрузка выше порога → новых атомов нет») само по себе опасно: одна упрямая буква может заблокировать весь курс. Три предохранителя.

**Уровень 1. Атом откладывается**
```
отложен ← 5 ошибок суммарно ИЛИ 3 неудачные встречи в разных сессиях
```
Отложенный атом **исключается из расчёта нагрузки**: он не выучен, но перестаёт считаться долгом, и ввод новых букв разблокируется. Из ротации он уходит на 2–3 сессии.

**Уровень 2. Возврат другим способом**
Долбить одно и то же упражнение бессмысленно: если человек пять раз перепутал `ب` и `ت`, шестой показ тем же способом ничего не изменит. При возврате меняется подход, а не количество:
- самый лёгкий режим: далёкие по форме варианты
- подсказка про отличительный признак («у `ث` три точки — как три»)
- переход на обводку: моторика часто пробивает то, что не пробивает узнавание

**Уровень 3. Облегчённый зачёт**
После двух откладываний атом засчитывается по сниженным требованиям:
```
2 верных подряд в самом лёгком режиме   (вместо 3 подряд в ≥2 типах)
→ known, но с флагом weak
```
Флаг `weak` — это долг, а не амнистия:
- такие атомы **чаще обычного попадают в слоги и слова** на этапах 2, 3 и 5
- флаг снимается при первом уверенном попадании там: буква доучивается в контексте, а не в лоб
- в справочнике «Алфавит» такая буква просто открыта, без отметки «освоено» — приложение не хвалит за то, чего не было

**Гарантия темпа**
```
если 2 сессии подряд не введено ни одного нового атома
    → ввести один новый принудительно, игнорируя нагрузку
```
Страховка на случай, когда долг по повторениям всё равно душит прогресс. Она работает только после выполнения дневного цикла повторений и не обходит обязательный рубеж алфавита.

**Потолок отложенных: 4 одновременно**

Предохранители выше нужны, чтобы человек не застревал. Но если они срабатывают свободно, появляется противоположная беда: с плохим стартом можно набрать десяток отложенных букв и формально не застрять, фактически не выучив ничего.

```
если |отложенных| > 4
    → гарантия темпа отключается
    → досрочно вернуть самый старый отложенный, в облегчённом режиме
    → шаблон «повторение», пока счётчик не упадёт до ≤ 4
```

Это правило сильнее гарантии темпа наряду с дневным циклом повторений и рубежами: новый материал не вводится, пока не разобран накопленный хвост. Досрочный возврат нужен, чтобы хвост вообще мог разбираться — иначе отложенные просто ждут своей паузы, а урок-повторение работает вхолостую.

**Потолок долга**
Очередь повторений ограничена ~25 атомами. При переполнении самый застоявшийся откладывается — очередь физически не может расти бесконечно.

`?` Все числа (5 ошибок, 2–3 сессии паузы, 25 атомов в очереди, 2 сессии без новых, потолок 4 отложенных, 2 успешных повтора после нового урока, порог 80% и граница 40%) подлежат калибровке на реальных данных.

### 6.5 Разделение ответственности

| Контент-менеджер решает | Алгоритм решает |
|---|---|
| какие понятия существуют и в каком порядке доступны | когда именно вводится следующая буква |
| условия разблокировки (рёбра графа) | сколько повторений в уроке и каких |
| тексты объяснений, аудио, примеры | какой шаблон применить сегодня |
| пороги нагрузки | нужен ли урок-повторение |
