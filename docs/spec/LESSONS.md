## 5. Сессия

- **До 20 заданий**, виден единый прогресс-бар с фактической длиной занятия. Обычно блоки закрепления, новое и повторение заполняют весь бюджет. Узкий урок из двух отдельных букв может закончиться раньше, если созревшего старого материала не хватает.
- Ошибка → показать верный ответ + короткое объяснение → вернуть задание через несколько шагов. Если такая же проверка этой буквы уже есть впереди, отдельная копия не добавляется; поэтому в узком двухбуквенном уроке одинаковый тест встречается не больше двух раз на букву. В полной сессии повтор заменяет добавочное задание, но не вытесняет обязательную форму или режим и не превышает бюджет.
- В обводке промах — штрих, который не продвинул текущую часть буквы: он стирается с холста сразу, а штрих, продвинувший часть из нескольких линий, остаётся. После **трёх промахов подряд по одной части** холст сам показывает, как пишется: открывает контур и показ, и по памяти, и по контуру. Кнопка «Не помню» в письме по памяти открывает тот же контур. Оба способа — подсказка, а не ответ или ошибка: окно результата не появляется и событие прогресса не записывается. Человек обводит по подсказке, и только собранная буква засчитывается верным ответом. Допуск проверки при этом не смягчается: подсказка честнее сниженной планки, а человек, у которого не выходит линия, не застревает на букве без помощи. `?` Число 3 подлежит калибровке.
- Ответ со второй попытки не даёт продвижения по состоянию атома, но и не считается повторной ошибкой.

Жизней / сердечек нет.

## 6. Уроки: граф вместо расписания

Фиксированной программы «урок 7 вводит `ج` и `ح`» **нет**. Такое расписание убивает адаптивность: буква вводилась бы независимо от того, готов человек или нет.

Хранятся **ограничения и заготовки**, а не последовательность. Порядок уроков выводит алгоритм.

Учебный контент — граф знаний, темы, шаблоны уроков, тексты объяснений, данные по буквам — лежит **JSON-файлами в ассетах приложения**. Версионируется через git, работает офлайн, правка требует релиза. Формат сразу проектируется так, чтобы те же файлы можно было подтягивать с сервера, когда контент начнёт меняться чаще релизов.

### 6.1 Граф знаний

Узлы — атомы и понятия, рёбра — «что после чего *можно* вводить».

```
понятие «формы»    requires: —
понятие «точки»    requires: [ا, понятие «формы»]
ب                  requires: [понятие «точки»]
ث                  requires: [ب, ت]
понятие «соединение» requires: [≥2 буквы в known]
понятие «огласовки»  requires: [≥8 букв в known]
```

Это не порядок уроков, а рёбра. Условия бывают двух видов: конкретные зависимости (`ث` после `ب` и `ت`) и пороговые (`≥8 букв в known`).

Пороговые условия считаются по **`known`, а не `mastered`**. `mastered` требует отложенных подтверждений: для букв — через 1/2/4 сессии, для остального материала — по календарю из §3. Привязка тем к нему задерживала бы курс даже тогда, когда человек всё уже узнаёт. `known` — это «узнаёт уверенно», и этого для открытия следующего понятия достаточно.

### 6.2 Шаблоны уроков

Не «урок 7», а «учебный блок такого типа». Шаблон задаёт структуру блока и правила подбора, но **не конкретные буквы**. Одна сессия может последовательно включать несколько таких блоков.

| Шаблон | Когда применяется | Состав |
|---|---|---|
| `введение понятия` | открылось новое понятие | длинный intro + закрепление понятия + повтор |
| `введение буквы` | нагрузка в норме, в графе есть доступный атом | intro + 1–2 новых атома + закрепление + повтор |
| `повторение` | нагрузка выше порога | только повтор, новых атомов нет |
| `соединение` | понятие «соединение» открыто | слоги из освоенных букв |

Блок **повтора берётся из общей очереди**, а не из атомов самой темы: иначе буквы прошлых уроков не возвращались бы никогда, и интервальное повторение существовало бы только на бумаге. Из двадцати мест не меньше четырёх резервируются возврату, остальные — теме урока. Слоты под возврат резервируются первыми, иначе тема съедает весь урок. Один атом занимает не больше пяти заданий, иначе урок вырождается в одну букву. Созревшие формы одной четырёхформенной буквы считаются одним семейным повтором и занимают один слот сборки.

Для полного блока ровно из двух отдельных букв действует более строгий предел: по четыре задания на букву — обводка, узнавание, письмо по памяти и произношение. Если голос технически недоступен, его место может занять второе узнавание, но третьего одинакового теста не будет. Все свободные места получают только буквы из интервальной очереди прошлых тем. Если такого повтора мало, занятие заканчивается раньше; следующая пара новых букв ради числа 20 в эту же сессию не вводится. Для остальных типов блоков планировщик по-прежнему может добавить следующий готовый цельный блок.

Очередь — интервальная. Атом, не дошедший до `known`, просится в повтор
каждый урок. Буквы и их формы после `known` возвращаются через 1, затем 2
и 4 сессии; каждый своевременный чистый повтор в новой сессии даёт одно
подтверждение, третье переводит форму в `mastered`. Несколько ответов в
одной сессии не увеличивают интервал. Ошибка откатывает форму в `learning`
и обнуляет подтверждения. Для остальных типов материала очередь сохраняет
общую схему 2, 4, 8, 16 сессий, а переход в `mastered` дополнительно требует
календарных интервалов из §3. Внутри очереди сначала недоученные, затем те,
у кого срок повторения вышел раньше.

Общий скелет сессии; части `пробел` и `новое` могут повторяться:
```
[ пробел ]     обязательный короткий добор недоученного
[ intro ]      объяснение нового цельного материала
[ новое + повтор ]  закрепление и очередь старого материала
[итог]         что выучено, что открылось
```

В уроке с новым материалом сначала каждая новая буква получает хотя бы одно задание. Затем возврат из общей очереди подмешивается в закрепление в случайных местах. Пока обе очереди не пусты, старый материал не идёт дважды подряд, а материал темы — больше двух раз подряд. Порядок упражнений одной буквы сохраняется: обводка по контуру не может оказаться после письма по памяти. Если нового материала нет, повтор остаётся одним блоком.

Каждый урок форм включает все заявленные формы букв темы в одном сеансе,
блоками по позиции (см. §2). Хотя бы одно задание выделяется каждой форме;
оставшиеся места идут на закрепление. Если у букв есть только конечные формы
(`د ذ ر ز`), достаточно одного блока. Ошибки возвращаются на повтор по §5.

Это правило действует при знакомстве с новым блоком и явном выборе
полного повтора темы в оглавлении. Автоматическое закрепление уже
показанного материала работает только с пробелами (см. §6.3).
Перед заданиями каждая форма темы получает объяснение. Лимит заданий,
накопленный прогресс и зависимости не могут исключать материал из темы.
Перед первой такой карточкой для каждой буквы показывается сводный обзор всех
её форм. Он не считается заданием, отдельным атомом или знакомством с ещё не
разобранными формами: их подробные карточки остаются в своих блоках.
До объяснений проверяется, что весь материал доступен и помещается вместе
с обязательным повторением старого. Если нет, нужно изменить порядок,
зависимости или разделить тему в программе курса; неполный урок не создаётся.

В `intro` для букв `ا د ذ ر ز و` обязательно показывается правило о несоединении влево.

### 6.3 Планировщик (на клиенте)

Перед началом и после каждого завершённого блока планировщик заново считает прогресс и выбирает следующую посильную цель:

1. Если одновременно отложено больше четырёх элементов — закрепление
   с досрочным возвратом самого старого отложенного.
2. Если есть начатый доступный блок с неосвоенным материалом — продолжаем
   его: ещё не показанное объясняем, уже показанное закрепляем коротко.
   Если весь блок уже показан, выбираем только неосвоенные элементы,
   начиная с тех, которые дольше не встречались. При нескольких
   таких блоках выбираем первый по программе в выбранном разделе.
   Этот приоритет сильнее нового понятия и гарантии темпа.
3. Если нагрузка выше порога — закрепление. После двух занятий без нового
   материала можно ввести доступный блок, но зависимости всё равно обязательны.
4. Иначе — первый незавершённый блок нового материала по порядку в
   оглавлении выбранного раздела. Техническая готовность более поздней темы
   не позволяет ей обогнать программу курса. Следующий этап начинается
   только после освоения или успешной входной проверки всех тем предыдущего:
   соединение нескольких букв не показывается до завершения этапа алфавита.
5. Если нового доступного блока нет — повторение из общей очереди. Когда срок
   повторения ещё не подошёл, ручной запуск занятия всё равно даёт практику
   знакомого материала, а не пустой экран.

Выход из занятия, просмотр объяснения и отметка о завершении не означают
готовность к следующему материалу. Готовность блока: понятия объяснены,
все проверяемые элементы достигли `known`; для базовых букв также выполнены
оба режима письма, если доступен контур, и произношение, пока оно включено.
Успешные режимы
считаются по всей истории верных ответов, включая медленные и исправленные;
достаточная уверенность проверяется отдельно состоянием `known`.
Зачёт `known + weak` по входной проверке или облегчённому критерию остаётся
исключением: обязательные учебные режимы не требуют повторного прохождения.

Сессия имеет верхний бюджет `tasksPerSession` (20 сейчас; число может быть откалибровано позже). Короткое закрепление — первый блок этой сессии, а не отдельное занятие. Если после него открылся новый цельный блок и все его обязательные задания помещаются в остаток, он вводится сразу. Иначе остаток заполняется повторением. Исключение — полный блок из двух отдельных букв: после него добавляется только созревший повтор старого материала, а при его нехватке сессия завершается с фактическим меньшим числом заданий.

Внутри короткого добора уже освоенные элементы не мешаются с пробелами. Если элемент уже в `known`, но пропущен обязательный режим, даётся только этот режим. Иначе нужно 2–3 встречи с учётом серии верных ответов и недостающих режимов. Ошибка возвращает задание, но не раздувает общий бюджет: повтор вытесняет добавочное, но не обязательное задание.

Если ошибка сбросила чистую серию буквы, добор восстанавливает не только
число ответов, но и нужное разнообразие режимов: один и тот же тест не может
быть единственным способом снова дойти до `known`. Предел в пять заданий на
атом считается по всему занятию, включая заново построенные блоки после
добора; исчерпанный пробел не заполняет собой остаток из двадцати заданий.

Фиксированная очередь незавершённого занятия не сохраняется. При каждом
возвращении материал и упражнения собираются по журналу ответов; число
заходов не открывает новые темы. Новых таблиц для этого нет. После серии
ошибок временно отложенный элемент не возвращается досрочно, кроме случая
из пункта 1: содержащий его блок ждёт окончания паузы, доступное повторение
продолжается по остальным элементам.

Мелкие авторские блоки в JSON задают цельный объём материала: группу базовых
букв или все соединённые формы этой группы. Темы служат оглавлением;
фиксированного числа занятий нет. Планировщик добавляет столько закреплений,
сколько требуется по знаниям, и после освоения добавляет новое.
Каждый следующий блок букв/форм требует освоенности предыдущего материала.
В новом блоке сохраняются все обязательные объяснения и упражнения из §6.2.
Проверка вместимости происходит до запуска; слишком большой блок нужно
разделить в контенте, а не исключать отдельные формы.

Соединение открывается после освоения двух букв и конкретных форм,
используемых в первом сочетании. Поздние сочетания требуют своих букв;
они вынесены в отдельные небольшие блоки. Поэтому соединять знакомые буквы
можно до окончания всего алфавита. В сочетаниях доступны задания в обе
стороны: выбрать запись по названиям букв и определить буквы по записи.
Хамза и другие знаки также получают вопросы в обе стороны, чтобы достижение
`known` не было невозможно из-за единственного режима.

Для графов без авторских блоков сохраняется подбор отдельных доступных
элементов. Числа нагрузки и гарантии темпа остаются настраиваемыми в коде.

### 6.4 Защита от застревания

Ограничение нагрузки («нагрузка выше порога → новых атомов нет») само по себе опасно: одна упрямая буква может заблокировать весь курс. Три предохранителя.

**Уровень 1. Атом откладывается**
```
отложен ← 5 ошибок суммарно ИЛИ 3 неудачные встречи в разных сессиях
```
Отложенный атом **исключается из расчёта нагрузки**: он не выучен, но перестаёт считаться долгом, и ввод новых букв разблокируется. Из ротации он уходит на 2–3 сессии.

**Уровень 2. Возврат другим способом**
Долбить одно и то же упражнение бессмысленно: если человек пять раз перепутал `ب` и `ت`, шестой показ тем же способом ничего не изменит. При возврате меняется подход, а не количество:
- самый лёгкий режим: далёкие по форме варианты
- подсказка про отличительный признак («у `ث` три точки — как три»)
- переход на обводку: моторика часто пробивает то, что не пробивает узнавание

**Уровень 3. Облегчённый зачёт**
После двух откладываний атом засчитывается по сниженным требованиям:
```
2 верных подряд в самом лёгком режиме   (вместо 3 подряд в ≥2 типах)
→ known, но с флагом weak
```
Флаг `weak` — это долг, а не амнистия:
- такие атомы **чаще обычного попадают в слоги и слова** на этапах 2 и 5
- флаг снимается при первом уверенном попадании там: буква доучивается в контексте, а не в лоб
- в справочнике «Алфавит» такая буква просто открыта, без отметки «освоено» — приложение не хвалит за то, чего не было

**Гарантия темпа**
```
если 2 сессии подряд не введено ни одного нового атома
    → ввести один новый принудительно, игнорируя нагрузку
```
Страховка на случай, когда долг по повторениям всё равно душит прогресс.

**Потолок отложенных: 4 одновременно**

Предохранители выше нужны, чтобы человек не застревал. Но если они срабатывают свободно, появляется противоположная беда: с плохим стартом можно набрать десяток отложенных букв и формально не застрять, фактически не выучив ничего.

```
если |отложенных| > 4
    → гарантия темпа отключается
    → досрочно вернуть самый старый отложенный, в облегчённом режиме
    → шаблон «повторение», пока счётчик не упадёт до ≤ 4
```

Это единственное правило, которое сильнее гарантии темпа: новые буквы не вводятся, пока не разобран накопленный хвост. Досрочный возврат нужен, чтобы хвост вообще мог разбираться — иначе отложенные просто ждут своей паузы, а урок-повторение работает вхолостую.

**Потолок долга**
Очередь повторений ограничена ~25 атомами. При переполнении самый застоявшийся откладывается — очередь физически не может расти бесконечно.

`?` Все числа (5 ошибок, 2–3 сессии паузы, 25 атомов в очереди, 2 сессии без новых, потолок 4 отложенных) подлежат калибровке на реальных данных.

### 6.5 Разделение ответственности

| Контент-менеджер решает | Алгоритм решает |
|---|---|
| какие понятия существуют и в каком порядке доступны | когда именно вводится следующая буква |
| условия разблокировки (рёбра графа) | сколько повторений в уроке и каких |
| тексты объяснений, аудио, примеры | какой шаблон применить сегодня |
| пороги нагрузки | нужен ли урок-повторение |
