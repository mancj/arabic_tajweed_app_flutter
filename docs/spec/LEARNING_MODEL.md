## 2. Ключевая идея: атом знания

Единица обучения — **не буква**, а **атом**.

```
Atom = (буква × форма) | огласовка | правило | слог | слово
```

Всё — прогресс, очередь повторений, разблокировки — считается по атомам.
Буква считается освоенной, когда освоены все её атомы.

### Формы

Модель честная: у разных букв разное число форм.

| Тип буквы | Формы | Кол-во |
|---|---|---|
| Соединяющиеся с обеих сторон | изолированная, начальная, средняя, конечная | 22 буквы × 4 |
| Не соединяющиеся влево (`ا د ذ ر ز و`) | изолированная, конечная | 6 букв × 2 |

Итого ≈ **100 атомов-форм**.

Правило «не соединяется со следующей буквой» — не отдельный урок, а **факт, показываемый в момент знакомства с буквой**, с примером разрыва в слове. Это правило проверяемо: в упражнении на сборку слова неверное соединение засчитывается как ошибка.

### Формы вводятся блоками внутри одного урока

После знакомства с отдельной буквой доступны её соединённые формы:

```
ب-изолированная  requires: понятие «точки»
ب-конечная       requires: ب-изолированная показана
ب-начальная      requires: ب-изолированная показана
ب-средняя        requires: ب-изолированная показана
```

Порядок не случаен: конечная форма ближе всего к изолированной (та же буква плюс соединительная черта справа), поэтому идёт второй. Начальная и средняя отличаются сильнее.

**Буква в `known`** = все её формы в `known`. Именно это считают пороговые условия тем. Изолированная форма требует три чистых ответа и обязательную практику; соединённой достаточно двух чистых ответов в двух режимах — отдельной проверки и сборки семейства. Это позволяет идеально пройденному цельному уроку форм закрыть тему за один сеанс, а ошибки по-прежнему оставляют конкретную форму в повторении.

Тема форм покрывается **за один сеанс**, последовательными блоками:
конечные формы всех букв темы → начальные → срединные → повторение старого.
Перед первой подробной карточкой соединённой формы каждой буквы показывается
обзор со всеми её существующими формами: отдельно → в начале → в середине →
в конце. У `ا د ذ ر ز و` в обзоре только отдельная и конечная формы.
Обзор даёт общую картину, но не вводит атомы и не влияет на прогресс.
Перед первым заданием с незнакомой формой показывается её объяснение,
включая формы в вопросе и вариантах ответа. Будущие блоки не добавляются
в варианты заранее. Чередование букв сохраняется внутри каждого блока.
Так урок не отмечается пройденным после обучения только конечным формам.

### Формы показываются в слове

Соединённая форма — начальная, средняя, конечная — показывается не только глифом с татвилями (`ـبـ`), но и коротким **словом-примером с подсветкой этой буквы**: и в общем обзоре, и на подробной карточке. В обзоре примеры собраны отдельным блоком под плитками форм. Глиф с хвостиками — абстракция; в слове видно, как буква на самом деле цепляется за соседей. Для несоединяющихся букв то же слово показывает разрыв. Слова задаются в контенте, по одному на форму, по возможности из уже введённых букв.

Чтобы соединение было легче рассмотреть, рядом с подсвеченной буквой оно
растягивается тремя татвилями (`ـــ`): у начальной формы — до следующей буквы,
у конечной — от предыдущей, у средней — с обеих сторон. Другие промежутки
слова не растягиваются. Цветом выделяются сама изучаемая буква и добавленные
к ней татвили, а соседние буквы остаются обычного цвета.

### Огласовки и слоги

Огласовка — **атом-знак**, а не свойство буквы. Их три:

```
фатха (َ ) → а
касра (ِ ) → и
дамма (ُ ) → у
```

Сочетание «буква + огласовка» — это атом типа **слог**. В контенте этапа 2
описаны три обязательных знака на ба и 39 сочетаний на остальных 27 буквах.
Отдельного нового блока слогов ба нет: второй урок переносит знакомые знаки
на `ت ك د ر`. Старые атомы `vowel.ba.*` сохраняются для истории и отладки,
но не требуются для завершения этапа. Непоказанные сочетания
не считаются изученными: их можно вводить позже в контексте слов. Состояние
каждого атома появляется только при первой встрече. Если человек путает
`بِ`, именно этот слог возвращается в очередь повторений.

Звучание необходимо для всех используемых сочетаний. Для каждой из 28 букв
подготовлены отдельные записи с фатхой, касрой и даммой в
`assets/audio/harakat/`; этап 2 ссылается на них через `audioAsset`. Первые
слова пока произносит системный арабский TTS на устройстве.

На этапе огласовок сначала берётся изолированная ба (`بَ / بِ / بُ`), затем
остальные 27 букв с выборочными огласовками. Фатха и касра обязательны на
`خ ص ض غ ط ق ظ` и `ر`; у мим и айн касра нужна для первых слов. На алифе
используются только `أَ / إِ / أُ`: хамза над ним при фатхе и дамме и под
ним при касре. Сукун на ро, особое чтение лям в имени Аллаха и другие формы
хамзы оставлены на потом. Короткие слова появляются после освоения трёх
знаков, 39 обязательных слогов и связок букв. Слово берётся из подготовленного списка,
состоит из знакомых букв и кратких огласовок и имеет собственный прогресс;
его не нужно порождать из всех возможных комбинаций. Перевод изучается позже.

У знака и слога разные результаты письма. Обводка и рисунок по памяти при
первом знакомстве записываются в атом огласовки. Задание со звучащим слогом
и пустой буквой записывается в атом слога: оно проверяет, что ученик услышал
нужную гласную и поставил знак в правильной области относительно буквы.
Оба варианта считаются активной практикой.

Сборка звучащего слога из двух плиток записывает один общий результат
целевому слогу в режиме `syllableBuild`. Ошибка буквы или знака объясняется
отдельно, но не создаёт событий для уже знакомых букв и огласовок в палитре.
Выбор из вариантов не считается активной практикой и не заменяет письмо.

Чтение слога вслух записывает общий результат в режиме `saySyllable`:
при знакомстве на ба — атому знака, при переносе — конкретному слогу.
Произношение считается активной практикой и, пока голос включён, требуется
для завершения темы вместе с письмом. Выход без произношения снимает это
требование у букв, знаков и слогов только до следующего запуска приложения,
не создавая учебной ошибки или поддельного успеха. Постоянный запрет
микрофона в системе учитывается отдельно при каждом запуске.

### Модель буквы

```dart
Letter {
  id
  arabicName        // ألف
  ruName            // алиф
  sound             // фонетическое описание
  audioName         // аудио: имя буквы
  audioSound        // аудио: звук буквы
  connectsLeft      // bool — false для ا د ذ ر ز و
  forms             // [isolated, final] | [isolated, initial, medial, final]
  dots { count, position }   // 0..3, above | below
  strokePaths       // SVG-пути для обводки, по форме
}
```

## 3. Состояния атома

```
new → introduced → learning → known → mastered
```

| Состояние | Смысл | Переход дальше |
|---|---|---|
| `new` | ещё не встречался | урок вводит атом |
| `introduced` | показали, не спрашивали | первое задание |
| `learning` | в активной ротации | 3 верных подряд **с первой попытки** в ≥2 режимах; для соединённой формы — 2 в ≥2 режимах |
| `known` | распознаёт уверенно | подтверждение после интервала + ≥1 успех в «активной» механике |
| `mastered` | закреплено | — |

**Активная механика** = письмо, произношение или сборка слова. Одних тапов по вариантам недостаточно для `mastered`: узнавание ≠ воспроизведение.

Ошибка сбрасывает атом **на одно состояние назад**, не в ноль.

Дополнительно у атома есть два независимых флага, см. §6.4:

| Флаг | Смысл |
|---|---|
| `отложен` | временно выведен из ротации, не считается долгом |
| `weak` | засчитан по облегчённому критерию, требует добора в контексте |

Для букв и их соединённых форм календарного ожидания нет: после `known`
они возвращаются через 1 → 2 → 4 сессии и после трёх своевременных чистых
повторов переходят в `mastered`. За одну сессию засчитывается не больше
одного подтверждения, сколько бы заданий по форме в ней ни было. Для
остального материала сохраняются календарные подтверждения через
1 → 2 → 4 → 7 дней. Правила задаются по типу атома, чтобы более простой
алфавит не наследовал строгость будущего запоминания слов.
