# Дизайн

Этот документ описывает общие правила интерфейса. Перед изменением экрана
читать его вместе с тематической спецификацией экрана.

## Отступы

`padding` и `margin` используют только значения дизайн-сетки: 4, 8, 12, 16,
24, 32, 48, 64, 80, 96 и далее. Значение 20 не использовать.

Связанные элементы располагаются ближе, отдельные смысловые группы — дальше.
Внутренний отступ карточки обычно составляет 24–32 px.

Промежуток между виджетами создаётся только через
`Margin.horizontal(...)` или `Margin.vertical(...)` из
`lib/app/widgets/margin.dart`. `SizedBox` используют только для размера
дочернего виджета или его геометрии, а не для отступа.

## Цвета

Цвета интерфейса хранятся в `lib/app/resources/ui_colors.dart`. Для каждого
нового цветового токена задавать значения и для светлой, и для тёмной темы;
виджеты получают их через `UIColors`, а не через локальные значения `Color`.

## Типографика

Переиспользуемые стили текста хранятся в `UITextStyles`. Обычный текст
интерфейса не создаёт локальный `TextStyle` и не собирает новый шрифт через
`copyWith` во виджете.

Стили называются по внешним характеристикам, а не по месту применения:
`regular12`, `semibold17`, `monoSemibold11`, `serifRegular16`. Названия вроде
`cardTitle`, `badge`, `hint` и `buttonTitle` не использовать: один и тот же
стиль может применяться в разных виджетах.

Для основного шрифта Onest семейство в названии опускается. Для остальных
семейств используется общий префикс: `mono`, `serif`, `playfair`, `arabic`.
Вес указывается единообразно: `regular` — 400, `medium` — 500, `semibold` —
600, `bold` — 700. Имя всегда должно соответствовать фактическому весу.
Если при одинаковых семье, весе и размере нужны разные высоты строки, вариант
получает универсальный суффикс `Compact` или `Relaxed`.

Один токен задаёт весь постоянный набор параметров: семейство и запасные
семейства, размер, вес, высоту строки, межбуквенный интервал и стандартный
цвет. Дубли и смысловые псевдонимы одного набора параметров не создаются.

`copyWith` допустим для контекстного цвета, подчёркивания, тени или другого
состояния, которое не меняет место текста в типографической системе. Размер,
вес, семейство, высоту строки и межбуквенный интервал через `copyWith` не
менять. Для двух состояний с разным весом выбирать между двумя готовыми
стилями, а не менять вес условием внутри `copyWith`.

Новый стиль добавляется, если набор параметров повторился второй раз или если
ради него пришлось бы изменить два и более типографических параметра готового
стиля. Например, сочетание JetBrains Mono, 11 px, веса 600 и интервала 0.8 —
самостоятельный `monoSemibold11`, а не изменённый `regular10`.

Исключение — учебные глифы и текст внутри карточек, которые целиком
масштабируются от макетного размера. Для них может меняться вычисляемый размер,
но семейство, вес, высота строки и запасные шрифты берутся из базового стиля.
Готовый токен карточки масштабируется через `UITextStyles.scaled`. Причина
другого исключения должна быть понятна из кода или короткого комментария.
