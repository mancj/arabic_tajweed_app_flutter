# Фиксированный список для озвучки

127 отдельных записей, все — слова из Корана. Искусственных сочетаний нет.
Каждая строка — один будущий MP3 с именем `audio/words/ID.mp3`.
Полные пути заданы в [words.json](words.json). Аудиофайлы пока не созданы.

Прочитать все написанные краткие гласные, включая последнюю, без пауз
между частями. Одна запись используется для раздельного и соединённого показа.
У каждого слова приведена ссылка на аят. Повтор слова в нескольких уроках
использует одну запись и не увеличивает число файлов для озвучки.

[Программа](README.md) · [Состав банка](COVERAGE.md)

Точные токены, ссылки, исходное уведомление и контрольная сумма сохранены
в [words.json](words.json). Номер слова относится к использованной выгрузке.
Отдельные учебные записи не являются новой редакцией коранического текста.
