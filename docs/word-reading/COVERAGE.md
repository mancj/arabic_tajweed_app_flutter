# Состав фиксированного банка

Банк содержит 127 записей, все — слова из Корана. Искусственных сочетаний нет.
Основной маршрут — 43 слова, контрольный запас — 12, дополнительный
запас для повторения — 72. Дополнительный запас не обязателен для завершения
перехода и не требует проходить все строки по очереди.

|---|---|---|

## Последовательность

- Урок 1: **لَكَ · مَعَ** — два новых коротких слова.
- Урок 2: **بِكَ · لَكِ · بِهِ** — три новых слова и повтор слов первого урока.
- Урок 3: **هُوَ · هِيَ** — два новых слова и повтор слов первых двух уроков.
- Уроки 4–7: только три буквы; 24 новых слова из Корана.
- Уроки 8–9: в каждом пять трёхбуквенных слов и одно четырёхбуквенное.
- Другие четырёхбуквенные слова — необязательный запас; их дают изредка среди трёхбуквенных.

Повторное появление слова не создаёт новую запись для озвучки.
В основной программе семь разных двухбуквенных слов. Редкая форма **نَكُ**
сохранена в дополнительном запасе и не вводится в первых уроках.

## Что проверяется

Кораническое происхождение каждой записи, конечный список, отсутствие
повторов строк, правильные огласовки и раздельный показ, устойчивые имена
аудиофайлов, ссылки на аят и порядок усложнения.
Все повторы внутри урока ссылаются на уже введённые слова.
Контрольные слова не показываются заранее в уроках или при подборе вариантов.

Полный перебор комбинаций не требуется. Нет требования давать каждую букву
с каждым знаком в каждой позиции, все 81 четырёхбуквенные схемы или два
близких искусственных варианта для каждого слова. Искусственные сочетания
запрещены в текущем списке; допустимое количество равно нулю.

## Границы материала

Только фатха, касра и дамма; длина от двух до четырёх букв с огласовками.
Мадд, сукун, шадда, танвин, та-марбута и хамза внутри слова изучаются позже.
Формы **مِنَ**, **لَمَنِ**, **لِمَنِ** исключены: их последний гласный связан
с чтением следующего слова и мешает использовать их как изолированный образец.

Коранические слова сохранены в исходном виде; раздельный показ — учебное
представление тех же букв. Наличие в Коране не проверяет качество будущей озвучки.
