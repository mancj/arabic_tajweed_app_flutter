# Программа чтения слов из отдельных букв

Статус: предложение для согласования. Подготовлены программа и конечный
список для будущей озвучки. Действующий курс и упражнения пока не изменены.
После завершения программы будут реализованы только выбранные ранее
форматы №1 и №3.

В конце второго этапа ученик постепенно собирает знакомые короткие слоги
в одно произнесённое слово. Каждая буква сохраняет отдельный вид:
**كَ تَ بَ** читается плавно, как одно слово. На третьем этапе те же слова
показываются соединёнными и с огласовками: **كَتَبَ**.

## Как усложняется материал

Сначала идут отдельные знакомые буквы с огласовками — например, **كَ** и
**تَ**. Затем три коротких урока посвящены только двум буквам. После них
основой становятся трёхбуквенные слова из Корана. Четыре буквы вводятся
позже и встречаются изредка среди более коротких слов.

Ниже девять предложенных уроков. В первых трёх вводятся по два-три
коротких слова; оставшееся время занимает повтор уже знакомых примеров.
Следующие уроки содержат по шесть новых слов. Это порядок введения
материала; повторения и исправление ошибок могут увеличить число занятий.
Первые три урока сохраняют длину в две буквы, давая время привыкнуть
к чтению нескольких слогов подряд. К трём буквам переходят после
уверенного чтения двух.

| Урок | Что добавляется | Примеры в обычном написании |
|---|---|---|
| 1 | Две буквы с фатхой | لَكَ · مَعَ |
| 2 | Две буквы с касрой | بِكَ · لَكِ · بِهِ |
| 3 | Две буквы: дамма и касра | هُوَ · هِيَ |
| 4 | Три буквы, преимущественно фатха | كَتَبَ · كَسَبَ · تَرَكَ · خَلَقَ · دَخَلَ · ذَهَبَ |
| 5 | Три буквы с касрой внутри | سَمِعَ · شَرِبَ · عَلِمَ · لَبِثَ · غَضِبَ · سَخِطَ |
| 6 | Три буквы с даммой и касрой | كُتِبَ · جُعِلَ · ضُرِبَ · وُضِعَ · نُفِخَ · ظُلِمَ |
| 7 | Три буквы: разные знаки и повтор букв | يَهَبُ · صُحُفِ · كَثُرَ · رُسُلُ · زُبُرِ · سُنَنَ |
| 8 | Первые четыре буквы среди коротких слов | أَذِنَ · أُذِنَ · إِرَمَ · حَفِظَ · طَبَعَ · خَلَقَهُ |
| 9 | Продолжаем три буквы и иногда четыре | ذُكِرَ · سَكَتَ · نَظَرَ · فَطَرَ · بُغِيَ · وَجَعَلَ |

Все примеры взяты из Корана; у каждого есть ссылка на аят
в [списке для озвучки](WORDS.md). Искусственных сочетаний нет.
В таблице перечислены новые слова. Во втором уроке повторяются слова
первого, в третьем — слова первых двух. Повторы записаны в `reviewWordIds`
и используют те же аудиофайлы. Отдельная озвучка для повторов не нужна.
В начальных уроках не требуется закрывать каждую возможную схему гласных.
**خَلَقَهُ** и **وَجَعَلَ** — первые два четырёхбуквенных примера.
В каждом из последних двух уроков такой пример только один на пять
трёхбуквенных слов. Дальше сохраняется тот же редкий показ четырёх букв.

### Когда вводить этот переход

Он появляется ближе к концу второго этапа, после знакомства с фатхой,
касрой и даммой. Точное место внутри действующего курса будет закреплено
при реализации упражнений; здесь зафиксированы материал и его порядок.
Перед каждым новым примером ученик должен знать все входящие в него
буквы с указанными знаками. Если конкретный слог ещё не встречался,
сначала отдельно показать и озвучить его существующей записью.
Например, перед **عَلِمَ** может понадобиться **لِ**, а перед **جُعِلَ** — **جُ**.
Не нужно ради этого заранее проходить все 84 сочетания.

Новые слова не требуют изучения перевода или грамматики. Медленный разбор
допустим; сначала закрепляется правильность, затем плавность чтения.
Во втором этапе буквы остаются раздельными при любой длине примера.
Третий этап продолжает чтение с огласовками, вводя соединённый вид букв.

## Конечный банк и объём программы

В [words.json](words.json) зафиксировано **127 записей**, все из Корана:

- **43 слова основного маршрута**;
- **12 слов для будущего контрольного чтения**;
- **72 дополнительных слова для повторения**.

Учебные сочетания полностью удалены. В первых трёх уроках используются
семь коротких слов и их повторы. Редкая короткая форма **نَكُ** остаётся
в дополнительном запасе; в первые уроки она не входит.

Основная программа не требует прочитать все 127 записей. Дополнительные
слова дают разнообразие повторений и запас для будущих вариантов ответа.
В запасе есть четырёхбуквенные слова; само их наличие не увеличивает
частоту показа четырёх букв. Все новые примеры выбираются из этого
конечного коранического списка.

Банк хранится явным списком. Во время занятия можно выбирать из него
записи и менять порядок показа. Нельзя составлять новые случайные звучащие
слова, произвольно менять огласовки или создавать неозвученные варианты.
Для будущего выбора звучания будут использоваться заранее озвученные
примеры этого банка. Для каждого слова создавать два почти одинаковых
искусственных ответа не требуется.

У каждой записи есть устойчивый ID, массив букв с огласовками, обычное
написание, раздельный показ и заранее заданный путь MP3. Например,
**كَتَبَ** имеет ID `kaf_a_ta_a_ba_a` и путь `audio/words/kaf_a_ta_a_ba_a.mp3`.
У сохранённых слов прежние ID и имена файлов не менялись. Аудио ещё
не записано и не подключено к приложению.

## Границы материала

Используются только фатха, касра и дамма. Различаются длина, порядок
гласных, буквы и их повторы. Полный перебор комбинаций не требуется:
нет обязательного покрытия каждой буквы с каждым знаком в каждой позиции,
всех 81 четырёхбуквенных схем или всех пар похожих букв.

Мадд, сукун, шадда, танвин, та-марбута, хамза внутри слова и особые
коранические знаки изучаются позже. **أَ / إِ / أُ** здесь обозначают
начальную хамзу с коротким гласным. Вав и йа используются как согласные
с собственным коротким гласным.

[Состав банка](COVERAGE.md) описывает фактически выбранный материал.
Это не доказательство эффективности методики и не проверка будущего аудио.

## Слова для будущей проверки

Эти 12 слов оставлены новыми: до соответствующего контроля их нельзя
показывать в объяснениях, повторениях или среди вариантов ответа.
Контрольные упражнения на этом шаге не реализуются.

| Когда | Новые слова |
|---|---|
| После программы раздельного чтения | جَمَعَ · حَسَدَ · رَجَعَ · شَكَرَ · صَبَرَ · غَفَرَ |
| После знакомства с соединённым чтением | صَدَقَ · بَعَثَ · رَفَعَ · وَهَبَ · حَمَلَ · كَفَرَ |

Первый набор показывается отдельными буквами. Второй впервые показывается
соединённым и с огласовками. Перед ним соединённый вид отрабатывается
на знакомых словах основного маршрута с той же озвучкой.

## Правила озвучки

Одна запись содержит всё слово или сочетание, произнесённое плавно,
без пауз между частями. Склеивание отдельных слоговых аудиофайлов не
заменяет естественную запись целого примера. Названия букв и русская
транслитерация в запись не входят.

Произносятся все написанные короткие гласные, включая последнюю:
**كَتَبَ** заканчивается на «а», **رُسُلُ** — на «у». Остановка при чтении
Корана изучается позже и здесь не заменяет написанное звучание.

Это учебное чтение отдельной записи. Оно не воспроизводит соседние слова,
удлинения при стыке слов или другие правила таджвида. Формы вроде **قُلِ**,
**خُذِ**, **مِنَ**, **لَمَنِ**, **لِمَنِ** не включены: последний гласный
в них связан с продолжением чтения следующего слова.
Коранические слова сохранены с исходными огласовками; раздельный показ —
представление отдельных букв, а не запись аята.

Одна MP3-запись используется на втором и третьем этапах. Она должна
соответствовать массиву `syllables` и сохранять краткость гласных.
Перед выпуском весь записанный список нужно прослушать.

## После завершения программы

Будут реализованы только ранее выбранные форматы:

- **№1:** показать раздельное слово и выбрать звучание из двух записей банка;
- **№3:** прочитать написанное слово вслух до предъявления образца.

Пока нет проверки произнесённого целого слова, сравнение с образцом
будет тренировкой без автоматического зачёта произношения.

## Источник и проверка

Коранические записи проверены по **Tanzil Quran Text**, вариант
[Simple Minimal](https://tanzil.net/docs/quran_text_types), полученный через
[Quran JSON](https://quran-json.risanb.com/text/simple-min/quran.json)
4 октября 2026 года. Каждое совпадение проверено как целое слово с теми же
огласовками; совпадения только по корню или после удаления знаков не
засчитывались. В `words.json` сохранены точный токен, сура, аят, позиция
в выгруженном тексте, ссылка на Tanzil, исходное уведомление и контрольная
сумма использованного файла. Нумерация слова относится к этой выгрузке;
для проверки человеком достаточно ссылки на суру и аят.

Данные Tanzil сохраняют указанные в исходном уведомлении условия
распространения. **Tanzil Project**, https://tanzil.net, CC BY 3.0.
Здесь подготовлены отдельные учебные записи, не новая редакция Корана.

Проверить список без создания новых слов:

```bash
python3 tool/validate_word_program.py
```

Проверка состава не требует сети. Для повторной сверки всех коранических
ссылок передайте сохранённую исходную выгрузку:

```bash
python3 tool/validate_word_program.py --source /path/to/quran-simple-min.json
```

Фиксированным источником будущей реализации остаются `words.json` и
`program.json`. Таблицы в этой папке предназначены для чтения и озвучки.
