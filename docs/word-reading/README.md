# Общий банк слов

Единственный редактируемый список —
[`assets/curriculum/words.json`](../../assets/curriculum/words.json).
Курс и отладка загружают его через `CurriculumLoader`; списков слов в Dart
и Python нет. [Таблица всех слов и записей](WORDS.md) создаётся из JSON.

## Подборки

`wordSets` содержит списки ID из общего банка:

- `harakaIntroduction` — простые двух- и трёхбуквенные примеры без внутренних
  разрывов для двух вводных сборок в огласовках. Частота и доступность слогов
  определяются курсом, а не банком.
- `wordReading` — слова действующего следующего раздела. `atomId` сохраняет
  прежний ID прогресса; `stage3.json` ссылается на запись через `wordId`.
- `wordBuildDebug` — примеры для отладки, включая разрывы и четыре буквы.

Остальные записи — запас для дальнейшего наполнения. Наличие слова в банке
не вводит его в курс. Будущие подборки можно добавить здесь же; общая сборка
не привязана к этапу огласовок и учитывает соединения между соседними буквами.

## Редактирование

У слова хранятся `id`, `joined` (обычное огласованное написание),
`syllableIds` (например, `kaf.fatha`), `audioFile` и источник.
Сейчас материал использует две–четыре буквы с фатхой, касрой и даммой.
Формы букв, раздельный показ и пропуск в упражнении вычисляются из состава;
их не нужно дублировать в JSON. У каждого добавленного слова должен быть источник.

Чтобы добавить пример, создайте запись и включите её ID в нужную подборку.
Уже используемые ID и имена MP3 сохраняйте: они связывают упражнения,
записи и прогресс. У слов следующего раздела сохраняйте также `atomId`.
После изменения состава `wordReading` пересоберите граф:

```sh
python3 tool/build_stage3.py
```

После любых правок обновите таблицу и проверьте банк:

```sh
python3 tool/word_bank.py --write
python3 tool/word_bank.py
```

Проверка ловит повтор ID/написания, неизвестные слоги и ссылки, неверную
огласовку, расхождение графа и подборки, отсутствие заявленной записи.
Она также сохраняет ограничение простых соединений во вводной подборке.

## Озвучка и источники

Текущие слова банка озвучены и имеют `recorded: true`. Записи находятся в
`assets/audio/words/`; карточки первых слов используют те же MP3.

Одна запись целого слова используется обоими упражнениями при любом пропуске.
Путь — `assets/audio/words/<id>.mp3`. Читать слитно и произносить последнюю
краткую огласовку. Пока `recorded` отсутствует или равен `false`, приложение
использует системный арабский TTS. После добавления MP3 установите
`recorded: true`; курс и отладка автоматически начнут использовать файл.

Коранические записи сохраняют точный токен, номер слова, ссылку на аят
и исходное уведомление Tanzil. Другие записи имеют собственный `source`;
они не объявляются кораническими. Для повторной сверки исходного корпуса:

```sh
python3 tool/word_bank.py --source /path/to/simple-min-quran.json
```
