# План развития упражнений «Читаем слова»

Статус: предложение для дальнейшего обсуждения. Сохранение плана не означает
внедрения или изменения действующих требований курса.

## Задача

Развивать чтение новых слов на знакомых буквах и огласовках. Уменьшить
многократную сборку одного и того же слова, сохранив полезную практику
соединённых форм, знаков и слитного чтения.

В текущем обычном цикле три из четырёх мест занимают сборки. Раздел использует
18 слов, хотя в общем банке уже есть 138 слов с подготовленными записями.
Есть риск, что пользователь запоминает последовательность действий и узнаёт
знакомые слова, но затрудняется прочитать новый пример.

Повторное чтение вслух с обратной связью помогает развивать беглость,
согласно [обзору National Reading Panel](https://www.nichd.nih.gov/publications/pubs/nrp/findings).
Эти данные относятся к обучению детей чтению; эффективность наших сборок
плиток ими не проверялась. Предложения ниже — гипотезы для приложения.

## Изменение практики

- Как начальную гипотезу использовать 1–2 успешные полные сборки слова,
  затем чаще предлагать новые слова той же сложности.
- Знакомые слова возвращать через интервал или после ошибок. Повтор не
  обязан каждый раз требовать полной сборки всех форм и огласовок.
- Расширять подборки из [общего банка](../../assets/curriculum/words.json),
  сохраняя постепенное усложнение: две буквы, три буквы, разрывы соединения,
  четыре буквы. Использовать реальные слова и готовые записи.
- Не превращать все 138 слов в новые обязательные уроки. Проверять, умеет ли
  пользователь применять знакомые способы чтения к меняющимся примерам.
- Отдельно решить, как отражать это в атомах и критериях завершения тем:
  оставить индивидуальное освоение слов или учитывать освоение способов
  чтения на разных словах. Алгоритм интервалов можно сохранить; решение
  об изменении единиц прогресса пока не принято.

## Предлагаемые упражнения

### 1. Поставь огласовки

Звучит целое слово. На экране уже соединённое написание без огласовок:
например, `كتب` для записи `كَتَبَ`.

Пользователь проставляет знаки плитками. Формы букв уже готовы, повторно
собирать их не требуется. После заполнения проверяется соответствие
огласовок записи.

Проверяет различение звучания и расположение знаков внутри соединённого
слова. Это практика подбора огласовок по звуку; она не заменяет проверку
самостоятельного чтения до предъявления образца.

### 2. Собери двумя частями

Звучит новое слово. Вместо отдельных выборов каждой формы и каждого знака
пользователь выбирает готовые соединённые фрагменты с огласовками.
Из двух частей получается целое слово.

Фрагменты строятся из банка с правильными формами на границах соединения.
Задание должно требовать меньше действий, чем полная сборка по буквам,
и направлять внимание на чтение групп букв.

### 3. Близкие варианты чтения

Усиление существующего задания «Послушайте и выберите слово».
Звучит запись, варианты имеют одинаковые буквы и различаются огласовками:
например, `كَتَبَ / كُتِبَ`.

Пользователь выбирает написание, соответствующее записи. Общий силуэт
не выдаёт ответ: нужно учитывать знаки. Для вариантов использовать
подходящие слова общего банка.

Это изменение подбора вариантов, а не обязательный новый экран.
Удалённое задание «Прочитайте слово и выберите его звучание» не возвращается.

### 4. Найди слово в строке

На экране строка из нескольких отдельных слов вместо отдельных карточек.
Звучит одно слово, пользователь касается его в строке.

Тренирует поиск и различение слов в строке справа налево. Сначала без
таймера. Подборка слов не объявляется связной фразой: чтение настоящих фраз
потребует отдельно подготовленного материала.

## Порядок работы

1. Расширить разнообразие материала внутри существующих уровней сложности.
2. Сократить повторные полные сборки уже получившихся слов.
3. Усилить существующий выбор написания близкими вариантами.
4. Первым новым форматом попробовать «Поставь огласовки».
5. Затем оценить необходимость сборки двумя частями и поиска в строке.

Оценивать не только разнообразие интерфейса, но и перенос навыка:
справляется ли пользователь с новым словом знакомой сложности, какие
огласовки и соединения вызывают ошибки, сколько действий требует задание.
Чтение нового слова до прослушивания образца проверять отдельно от выбора
написания после записи. Успешная серверная заглушка произношения пока
не подтверждает правильность самостоятельного чтения.
