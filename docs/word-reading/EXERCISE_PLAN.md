# Новые упражнения «Читаем слова»

Статус: предложения для дальнейшей работы; новые механики пока не внедрены.
Действующие правила профилей и программы курса описаны в
[модели обучения](../spec/LEARNING_MODEL.md),
[подборе уроков](../spec/LESSONS.md) и
[структуре курса](../spec/CURRICULUM.md).

Цель — тренировать чтение разных слов знакомой сложности и уменьшать
число отдельных действий. Проверять перенос навыка на новые примеры,
а не только узнавание ранее собранных слов.

## Предлагаемые упражнения

### 1. Поставь огласовки

Звучит целое слово. На экране уже соединённое написание без огласовок:
например, `كتب` для записи `كَتَبَ`.

Пользователь проставляет знаки плитками. Формы букв уже готовы, повторно
собирать их не требуется. После заполнения проверяется соответствие
огласовок записи.

Проверяет различение звучания и расположение знаков внутри соединённого
слова. Это практика подбора огласовок по звуку; она не заменяет проверку
самостоятельного чтения до предъявления образца.

### 2. Собери двумя частями

Звучит новое слово. Вместо отдельных выборов каждой формы и каждого знака
пользователь выбирает готовые соединённые фрагменты с огласовками.
Из двух частей получается целое слово.

Фрагменты строятся из банка с правильными формами на границах соединения.
Задание должно требовать меньше действий, чем полная сборка по буквам,
и направлять внимание на чтение групп букв.

### 3. Близкие варианты чтения

Усиление существующего задания «Послушайте и выберите слово».
Звучит запись, варианты имеют одинаковые буквы и различаются огласовками:
например, `كَتَبَ / كُتِبَ`.

Пользователь выбирает написание, соответствующее записи. Общий силуэт
не выдаёт ответ: нужно учитывать знаки. Для вариантов использовать
подходящие слова общего банка.

Это изменение подбора вариантов, а не обязательный новый экран.
Удалённое задание «Прочитайте слово и выберите его звучание» не возвращается.

### 4. Найди слово в строке

На экране строка из нескольких отдельных слов вместо отдельных карточек.
Звучит одно слово, пользователь касается его в строке.

Тренирует поиск и различение слов в строке справа налево. Сначала без
таймера. Подборка слов не объявляется связной фразой: чтение настоящих фраз
потребует отдельно подготовленного материала.

## Порядок дальнейшей работы

1. Первым новым форматом попробовать «Поставь огласовки».
2. Затем оценить необходимость сборки двумя частями и поиска в строке.

Близкие варианты уже предпочитаются существующим заданием выбора,
если в доступном материале есть слова с одинаковыми буквами и другими
огласовками. Расширять такие подборки можно дальше через общий банк.

Оценивать перенос навыка: справляется ли пользователь с новым словом
знакомой сложности, какие огласовки и соединения вызывают ошибки,
сколько действий требует задание. Самостоятельное чтение до образца
проверять отдельно от выбора написания после записи. Успешная серверная
заглушка произношения пока не подтверждает правильность чтения.
