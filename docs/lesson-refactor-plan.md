# Рефакторинг экрана урока

Цель: сохранить поведение этапов 1–2 и оставить общий ход урока пригодным для
огласовок и слов. Работа идёт небольшими шагами; каждый пункт закрывается
только после проверки связанных сценариев.

- [x] **1. Зафиксировать исходное состояние.** Проверить связанные тесты,
  отделить существующие изменения пользователя от файлов этой работы.
- [x] **2. Вынести логику объяснений и раскладки форм.** Сделать чистые классы
  для очереди карточек и оценки раскладки; контроллер оставляет запись
  событий и переходы между экранами. Сохранить порядок карточек и частичный
  зачёт форм.
- [x] **3. Отделить механики ввода.** Состояние обводки, раскладки форм и
  попыток произношения вынести из основного контроллера в небольшие обработчики.
  Общая `LessonSession` остаётся единственным местом учёта ответов.
- [x] **4. Отвязать представление задания от букв.** Ввести типизированное
  описание вопроса, ответа и обратной связи. Вынести выбор записи звука
  из `letterId`, оставив старые записи работающими. Специальные карточки
  форм оставить в буквенном представлении.
- [x] **5. Упростить экран и ход занятия.** Разделить крупные части
  `LessonPage` по назначению; вынести подбор следующего блока из контроллера,
  сохранив общий экран и прежнюю логику повторения.
- [x] **6. Проверить результат.** Запустить форматирование, анализ и
  связанные регрессионные тесты. Проверить, что контроллер координирует
  компоненты, а экран не содержит правил о видах учебного материала.

Ограничения: новые уроки и правила курса здесь не добавляются. В `pubspec.yaml`,
`course_path_page.dart` и `todo/todo.md` уже есть сторонние незавершённые
изменения; эта работа их не трогает. Коммитов не создавать.

Исходная проверка на проектном Flutter 3.44: 41 тест прошёл, 3 теста в
`lesson_completion_test.dart` падали до изменений из-за попадания на окно
результата вместо кнопки под ним. Прогон через системный Flutter 3.38
непригоден: зависимости требуют Dart 3.11–3.12.

Итог: 50 связанных тестов проходят, анализ изменённых файлов не находит
замечаний. Проверка всего проекта по-прежнему показывает падения в тестах
SVG/обводки вне этого рефакторинга и 19 замечаний анализатора в других файлах.
Три прежних падения `lesson_completion_test.dart` исправлены: тестовый сценарий
проверяет ход урока через контроллер, а экран не открывает окно для уже
закрытого ответа.
