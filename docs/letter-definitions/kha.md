# Ха — خ

**خ** похожа по звучанию на русское **«х»**, но произносится глубже.

## Как пишется

По форме такая же, как **ح**, но с **одной точкой сверху**.

## Махрадж — как произнести

Поднимите заднюю часть языка к мягкому нёбу, оставив щель для воздуха.
Плавно выдохните со звуком «х». Звук образуется в верхней части горла,
ближе ко рту.

## Сыфат — как звучит

**خ** — буква с **объёмным звучанием**. Задняя часть языка поднимается
к нёбу, и звук становится более твёрдым. Говорить громче для этого не нужно.

Поэтому **خَ** на слух может напоминать «хо»: гласный «а» приобретает
более глубокий, твёрдый оттенок. Округлять губы
для русского «о» не нужно.
