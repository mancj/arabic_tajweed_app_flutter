# Фа — ف

Произносится как русское **«ф»** в слове «фара».

## Как пишется

У **ف** небольшая округлая головка и длинная нижняя часть,
похожая на неглубокую чашу. Сверху — **одна точка**.

## Сыфат — как звучит

**ف** произносится без голоса — слышен только шум воздуха.
Воздух проходит непрерывно, поэтому звук можно плавно тянуть: «ф-ф-ф».
