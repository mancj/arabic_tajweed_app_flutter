## Карточки приложения

Все 30 конспектов (две вступительные карточки и 28 букв) перенесены в
`assets/explanations/ru/`. Markdown-файлы остаются редакционными исходниками;
после согласования правки нужно перенести в соответствующий YAML.
Разделы махраджа и сыфата сохраняются только там, где они есть в конспекте.
Раздел «Как пишется» переносится в отдельный блок `writing` у каждой буквы.
В приложении он отображается после разбора, перед махраджем и сыфатом.

Вступление — `concept.letter.yaml`, махрадж и сыфат — `concept.makhraj.yaml`.
Для букв используется `<имя>.isolated.yaml`. Большинство имён совпадают
с Markdown; исключения:

| Конспект | YAML |
|---|---|
| `ha.md` (ح) | `hha.isolated.yaml` |
| `haa.md` (ه) | `ha.isolated.yaml` |
| `sad.md` | `sod.isolated.yaml` |
| `dad.md` | `dod.isolated.yaml` |
| `taa.md` | `to.isolated.yaml` |
| `zha.md` | `zho.isolated.yaml` |
| `qaf.md` | `qof.isolated.yaml` |

Оригиналы изображений находятся в `images/`. JPEG-копии 1024 × 1024 для
приложения — в `assets/img/`, с теми же базовыми именами. Пропорции сохранены,
схемы не обрезаны; свободное место дополнено фоном.
В YAML изображения подключаются через `resource:assets/img/<имя>.jpg`.
