# Карточки объяснений

Одна карточка — один YAML-файл в `assets/explanations/ru/`.
Карточка курса: [`ba.isolated.yaml`](../assets/explanations/ru/ba.isolated.yaml).
Все типы блоков собраны в отдельном [образце](../assets/explanations/ru/ba.yaml).

## Формат

```yaml
title: Буква Ба
blocks:
  - text: |
      У буквы Ба **одна точка снизу**.
  - letter: {glyph: ب, audio: audio/alphabet/ba.wav}
  - makhraj: |
      Сомкните губы, затем разомкните их со звуком «б».
  - sifat: |
      Ба произносится с голосом. Сам звук «б» остаётся коротким.
  - forms:
      - {position: isolated, glyph: ب}
      - {position: initial, glyph: بـ, example: {text: بات, highlight: 0}}
  - word: {text: بات, highlight: 0, form: initial}
  - examples:
      - {glyph: بَ, audio: audio/harakat/ba_fatha.mp3}
      - {glyph: بِ, audio: audio/harakat/ba_kasra.mp3}
  - sound: {label: Звук буквы, audio: audio/alphabet/ba.wav}
```

`title` обязателен. `blocks` содержит хотя бы один блок. Каждый блок имеет
ровно один ключ, определяющий его тип. Порядок в файле задаёт порядок на экране.
`letter` показывается отдельным учебным образцом с направляющими строками
и подписанной кнопкой «Слушать». Если он открывает документ с текстом,
название и отметка «Новая тема» находятся рядом с буквой. Длинное слово
и увеличенный системный текст используют всю ширину.
Текстовые блоки, `makhraj` и `sifat` объединены в одну страницу. Разделы
«Разберём», «Как произнести» и «Как звучит» пронумерованы и разделены
тонкими линиями. Их значения — Markdown-текст, порядок остаётся авторским.
Каждый раздел использует `RuleCard(flat: true)` без собственной рамки и тени.

### Как выбирается компоновка образца

Компактный режим располагает заголовок слева, начертание справа. Он выбирается,
если есть заголовок, внутренняя ширина карточки не меньше 260 логических px,
системный масштаб превращает текст 16 px в размер не больше 21 px, а в образце
не больше четырёх Unicode-символов **без учёта черт соединения `ـ`**. Например,
`ــتــ` содержит одну букву и четыре такие черты, поэтому показывается справа.
Огласовки пока входят в этот подсчёт: слово `دَرَسَ` занимает всю ширину.
Если хотя бы одно условие не выполнено, начертание переносится под заголовок.

После промежутка 16 px оставшаяся ширина компактного ряда делится 3:2 между
заголовком и образцом. Область образца имеет высоту 128 px; базовый размер
арабского шрифта — 96 px, внутри есть боковые поля по 16 px. `FittedBox` с
`scaleDown` уменьшает начертание, если оно не помещается, сохраняя пропорции.
Черты соединения исключены только из выбора режима: сам рисунок остаётся целым.

| Блок | Значение | Отображение |
|---|---|---|
| `text` | Markdown-текст | Абзацы, жирный, курсив, списки, заголовки, ссылки |
| `letter` | `glyph`, необязательные `audio` и `caption` | Начертание и кнопка звука |
| `makhraj` | Markdown-текст | Раздел о месте образования звука |
| `sifat` | Markdown-текст | Раздел о свойствах звука |
| `forms` | Список: `position`, `glyph`, необязательное `example` | Формы и примеры слов |
| `word` | `text`, `highlight`, необязательное `form` | Слово с подсветкой |
| `examples` | Список: `glyph`, необязательные `audio` и `caption` | Сетка примеров со звуком |
| `sound` | `label`, `audio` | Подписанная кнопка воспроизведения |

Все иллюстрации живут в YAML: начертания, слова-примеры, огласованные звуки
и ссылки на аудиофайлы. Карточка не ищет их по ID атомов в JSON. В `word`
и в примере внутри `forms` поле `highlight` — индекс подсвечиваемой буквы
в строке `text`, начиная с нуля. `position` и `form` принимают значения
`isolated`, `initial`, `medial`, `finalForm`. Порядок форм в списке задаёт
порядок их отображения. Аудио указывается по пути внутри `assets/`,
например `audio/harakat/ba_fatha.mp3`; файл должен входить в `pubspec.yaml`.
Для системного арабского голоса используется `tts:بَ`.
Если у элемента `audio` нет, кнопка воспроизведения не показывается.

JSON курса хранит порядок тем, условия их открытия и атомы, по которым
считается прогресс. Слово, приведённое только как пример в объяснении,
достаточно записать в YAML. Слово, которое потом будет отдельным заданием,
остаётся атомом курса. Аудио, используемое только в карточке, также
указывается только в YAML.

Внутри `text` используется `flutter_markdown_plus`: текст отображается
Flutter-виджетами. Обработчик ссылок передаётся через `onTapLink` у
`ExplanationCard`. По умолчанию ссылки `http` и `https` открываются во внешнем
браузере, в том числе в уроке и справочнике. Экран может передать свой
`onTapLink`, если ему нужна другая навигация. HTML внутри текста не поддерживается.

## Подключение к курсу

В объект атома добавляется необязательное поле:

```json
"explanationAsset": "assets/explanations/ru/ba.isolated.yaml"
```

Урок загружает и проверяет все указанные карточки до начала занятия. Одинаковый
путь читается один раз за загрузчик. Ошибка содержит имя файла, а ошибки блоков
также содержат индекс `blocks[N]`, начиная с нуля. Неизвестные поля и типы,
пустые карточки, некорректные слова и пути к звуку считаются ошибками контента.

Все атомы трёх этапов ссылаются на YAML-карточки. Заголовок, текст,
начертания и иллюстративные слова задаются в них. У изолированных букв
`formsOverviewAsset` указывает на одну из 28 сводных карточек форм.
Очередь урока показывает её перед подробными карточками соединённых форм.
Экран темы и проверка знаний читают те же YAML-файлы. В JSON остаются
атомы, связи курса и данные для заданий; полей `note` и `example` там нет.
Генераторы JSON сохраняют ссылки на карточки и не перезаписывают YAML.

Первые два объяснения Stage 1 — `concept.letter.yaml` (приветствие из
`introduction.md`) и `concept.makhraj.yaml` (из `makhraj-and-sifat.md`).
Они входят в тему `m.first` перед четырьмя первыми буквами.
Тексты семи изолированных букв `alif`, `ba`, `ta`, `tha`, `jim`, `hha`, `kha`
перенесены из `docs/letter-definitions/`, а их махрадж и сыфат выделены в
собственные блоки; исходный `ha.md` — это ح (`hha`),
а не ه (`ha`). При обновлении исходников нужно обновить соответствующий YAML.
Изображения в Markdown подключаются как
`![Описание](resource:assets/img/ba-makhraj.jpg)` и доступны офлайн;
файл должен входить в ассеты приложения. В карточке изображения показываются
со скруглением углов 16 px.

В уроке единственная буква в YAML-карточке звучит автоматически после
появления; кнопка позволяет прослушать её снова или остановить. В экране
содержания темы автозапуска нет, поскольку там открывается сразу несколько
карточек. Несколько букв в одном YAML-файле тоже не запускают звук
одновременно. Примеры без доступного звука показываются без кнопки.

## Код и расширение

- `ExplanationDocument` и подтипы `ExplanationBlock` описывают формат.
  Поля разбираются с помощью `json_serializable`.
- `ExplanationContent` проверяет внутреннее содержимое карточки.
- `ExplanationLoader` читает YAML из `AssetBundle` и сохраняет результат
  для повторных обращений.
- `ExplanationCard` собирает текст, формы и примеры в `RuleCard`, блоки
  `makhraj` и `sifat` — в разделы `RuleCard`, а `letter` — в
  `LetterWidgetCard(specimen: true)`. Внутри используется `LetterSpecimen`;
  обычный вид карточки остаётся у упражнений. Для этих виджетов
  создаются временные модели из YAML; прогресс по ним не записывается.

Для нового блока нужно добавить подтип, его ключ в `ExplanationBlock.decode`,
проверку содержимого и отображение в `ExplanationCard`. Исчерпывающий `switch`
поможет найти места, где новый тип ещё не обработан. После изменения модели:

```sh
.fvm/flutter_sdk/bin/dart run build_runner build
```

Ряды, колонки и другие способы компоновки можно добавить отдельными блоками
с вложенными списками. Сейчас карточка располагает блоки вертикально.
Стили и отступы задаются в коде, чтобы карточки выглядели одинаково.
Для нового языка создаётся соседний каталог и добавляется в `pubspec.yaml`;
ссылки на файлы задаются явно, автоматического выбора языка пока нет.

Документация библиотек: [YAML](https://pub.dev/packages/yaml),
[Flutter Markdown Plus](https://pub.dev/packages/flutter_markdown_plus).

## Дизайн объяснения · сентябрь 2026

Концепция — страница учебника с образцом арабского письма. Тёплая бумага,
тёмные чернила, крупная буква и компактные номера направляют чтение.
Название, начертание и звук находятся вместе; текст доступен обычной
прокруткой. «Понятно» сохраняет прежнее действие и остаётся у нижнего края.
Основной шрифт — Onest, учебное начертание — Scheherazade New. Текст 16/24,
подзаголовки 17–20, название 29; номера 13, метка 11. Поля 24, интервалы 8–16.
Новые цвета заданы парами светлой и тёмной темы в `UIColors`: `studyAccent`,
`inkSurface`, `onInk`.

Образец появляется за 480 мс с коротким подъёмом на 12 px, как положенный
на страницу лист. При воспроизведении нижняя направляющая показывает
реальный прогресс аудио, кнопка меняется на «Остановить». Сокращённое движение
убирает подъём и анимацию кнопки, сохраняя звук, состояние и прогресс.
Тактильный отклик использует общий `AppGestureDetector`; дополнительных
звуковых эффектов поверх учебной записи нет.
