# Идеи упражнений для огласовок

Предложения для обсуждения, а не действующее ТЗ. Реализованные механики,
их включение в курс и правила прогресса описаны в [упражнениях](../spec/EXERCISES.md).
Сборка слога и чтение вслух включены в курс; поиск одинаковой огласовки
доступен только в отладке. Их описание здесь не дублируется.

## Следующие возможные задания

| Идея | Пример и цель |
|---|---|
| Исправить огласовку | Показано `بُ`, звучит `بِ`: заменить знак. Иногда всё верно, тогда ответ «Уже правильно». |
| Перенести огласовку | Звучит `بِ`, показана `م`: получить `مِ`, выделив гласную независимо от согласной. |
| Определить изменение | `بَ → بِ`, `بَ → تَ` или одинаковые слоги: изменилась буква, знак или ничего. Сначала с написанием, потом только на слух. |
| Сравнить гласные на слух | `بِ / مِ` и `بِ / بُ`: одинаковая ли огласовка? Написания раскрываются после ответа. |
| Диктант с повторениями | Даны `ب م ر`, звучат `بِ مِ رَ`: расставить знаки из постоянной палитры. Один знак можно использовать повторно; у каждой карточки свой звук. |
| Найти адрес знака | В соединённом `شرب` найти букву услышанного `رِ` и поставить под ней касру. |
| Восстановить пропуск | В знакомом `شَرِبَ` скрыт один знак, звучит целое слово. Затем скрывать два знака без изменения соединений. |
| Найти ошибку диктора | Написано `شَرِبَ`, диктор ошибается в одной позиции: выбрать её и услышанный знак. Нужны проверенные записи намеренных ошибок и верные примеры. |
| Огласовать целое слово | Звучит `شَرِبَ`, показано `شرب`: расставить все знаки, сохраняя верные после ошибки. Помощь отдельными слогами учитывать отдельно. |
| Перенести последовательность | Звуковой образец `بَ بِ بَ` → знаки в `شرب`. Каждый звук доступен отдельно; готовое слово звучит после ответа. |
| Собрать звучание слова | Для каждой позиции `شَرِبَ` выбрать запись слога, затем послушать естественную запись всего слова. Склейка слогов её не заменяет. |
| Различить чтения одной основы | `شَرِبَ / شَرَبَ`: варианты отличаются одним знаком; нужны проверенные звуковые записи. |
| Проверить строку | Найти и исправить все несовпадения звука и знаков в нескольких карточках; число ошибок неизвестно, ответ «Всё правильно» доступен всегда. |

Начать обсуждение с исправления знака, переноса огласовки и диктанта
с повторениями. После перехода к словам — с одного пропуска и вариантов,
различающихся одним знаком. Голосовая проверка целых слов — отдельная будущая задача.

## Условия реализации

- Каждый пропуск имеет однозначный ориентир: запись или явно заданный образец.
  Неогласованная буква или слово сами по себе нужного чтения не задают.
- Все используемые слоги сначала вводятся. Наличие аудио ещё не означает,
  что ученик знаком с сочетанием; расширять обязательный маршрут до 84 слогов необязательно.
- При проверке огласовки согласная сохраняется, при проверке буквы — огласовка.
  Составление неверных вариантов слова из знакомых частей требует согласования с §4 ТЗ.
- Самостоятельный ответ отделяется от ответа после помощи. Исправление
  раскрытого ответа выполняет практику, но не увеличивает чистую серию.
- Повторы одного слога внутри задания оцениваются по позициям и не дают
  автоматически несколько независимых подтверждений в прогресс.
- Ошибка слова пока меняет только прогресс слова. Учёт его частей как
  отдельных слогов требует изменения модели обучения и правил проверки.
- Для диктанта нужен редактор знаков с повторным использованием палитры:
  нынешняя сборка форм расходует плитки и объединяет результаты по ID атома.
  Переиспользовать существующие карточки, звук и запись голоса по [CLAUDE.md](../../CLAUDE.md).

Дополнительные варианты: повторять букву в серии, чередовать старое и новое,
менять знакомое начертание или читаемый шрифт. Другой голос требует новых
проверенных записей; тембр и громкость не должны подсказывать ответ.
