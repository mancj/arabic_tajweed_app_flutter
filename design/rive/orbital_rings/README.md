# Orbital Rings

Векторное повторение предоставленной GIF-анимации с концентрическими кольцами.

- [Редактируемый проект в Rive](https://editor.rive.app/file/untitled/2619437). Имя файла в облаке — `Untitled`, артборд — `Orbital Rings`.
- `orbital_rings.riv` — экспорт для приложения, 3675 байт.
- Копия в приложении: `assets/rive/orbital_rings.riv`. Просмотр: «Отладка → Компоненты → Орбитальные кольца»; доступны пауза, продолжение и запуск сначала.
- Для использования в Flutter импортируйте `package:arabic_tajweed_app/app/widgets/ui_kit/orbital_rings_widget.dart` и вставьте `const OrbitalRingsWidget()`. Родитель задаёт ширину; виджет остаётся квадратным. Цвет можно передать через `color: Colors.blue`, толщину колец — через `ringThickness: 1.8`, толщину мелких вращающихся штрихов — через `dashThickness: 2.2` (1 — исходный вид, 3 — максимальная толщина). Прежний `thickness` задаёт обе толщины сразу, если отдельные значения не указаны. Воспроизведением можно управлять через `playing: false`. Цвет и толщина меняются без перезапуска анимации. В виджете чёрный фон файла преобразуется в прозрачность, поэтому виден фон родителя.
- `preview.png` — изображение начального состояния из Rive.
- Холст: 600 × 600. В исходном Rive-файле фон чёрный; при отображении в приложении он прозрачный. Четыре кольца, три группы по 12, 14 и 15 пар штрихов.
- Толщина меняется при выводе в Flutter. При разных значениях неподвижные кольца скрываются в кадре Rive и рисуются поверх с нужной толщиной; вращающиеся штрихи проходят через отдельный фильтр. Кадр Rive рисуется один раз, контроллер остаётся один. Параметры не записаны в исходный `.riv`.
- Анимация `Orbit Loop`: 512 кадров при 60 fps, 8,533 секунды, линейное вращение по часовой стрелке с бесшовным повтором.
- За цикл группы поворачиваются на 120°, 154,285714° и 240°. Скорости близки к измеренным в исходном GIF; исходник длится 8,52 секунды при 25 fps.
- Машина состояний `Orbit Player` автоматически запускает `Orbit Loop`. Проверен переход из Entry и работа в течение 540 кадров.
- Для просмотра в редакторе выберите Animate → Orbit Loop → Play. Цвета, размеры, пути и ключевые кадры можно менять в проекте.
- Экспорт редактируемой резервной копии `.rev` отклонён Rive: для него требуется другой тариф. Редактируемый исходник доступен по ссылке выше.
