# Правила работы в проекте

Перед выполнением любой задачи всегда читать [CLAUDE.md](CLAUDE.md),
ссылаться на него как на источник правил проекта и следовать его инструкциям.

Создавать коммиты только по явному разрешению пользователя на конкретный
коммит. Завершение задачи само по себе не даёт разрешения на коммит.

Если пользователь просит отправить, залить или опубликовать iOS-сборку в
TestFlight/ТФ, делегировать всю операцию проектному агенту
`testflight_deployer`, дождаться его результата и не запускать второй выпуск
параллельно в основном агенте.
