# Варианты иллюстраций махраджа

Созданы встроенным image_gen для выбора визуального стиля. Это концепты одной сцены, без привязки к конкретной букве; положения органов для каждой буквы будут прорабатываться отдельно.

Ориентиры: просмотренные в Simulator главный экран и экран завершения урока в светлой теме; палитра lib/app/resources/ui_colors.dart. Правила проекта: CLAUDE.md.

1. 01-outline.png — контурная схема.
2. 02-paper.png — слои бумаги.
3. 03-relief.png — мягкий объёмный рельеф.
